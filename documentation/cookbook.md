# Cookbook

You know what you want. This page points you straight at it. Each recipe is one
task with the shortest path to a working result. For the full story behind a
recipe, follow its guide link.

If you would rather learn in order, start with
[your first video](getting-started/your-first-video.md) and the twelve runnable
lessons in the example app.

## Text and motion

- **Fade or slide a title in.** See [Animating elements](guides/animating-elements.md) for the one motion list and the preset menu.
- **Type text out like a terminal.** Use `Typewriter`; see [Text and typography](guides/text-and-typography.md).
- **Count a number up.** Use `Counter`; see [Charts and data](guides/charts-and-data.md).
- **Stagger a list of items.** Use `Stagger`; see [Animating elements](guides/animating-elements.md).

## Scenes and timing

- **Play scenes one after another.** See [Scenes and transitions](guides/scenes-and-transitions.md).
- **Wipe or fade between scenes.** Use `Transition`; see [Scenes and transitions](guides/scenes-and-transitions.md).
- **Start an animation when another finishes.** Use a `Trigger` and an `Anchor`; see [Timing and triggers](guides/timing-and-triggers.md).
- **Carry one element across a scene cut.** Use `SharedElement`; see [Scenes and transitions](guides/scenes-and-transitions.md).

## Media

- **Show a photo or a logo.** Use `Image`; see [Images and video clips](guides/images-and-video-clips.md).
- **Embed an existing video clip.** Use `Clip`; see [Images and video clips](guides/images-and-video-clips.md).
- **Pan and zoom across the frame.** Use `Camera`; see [Scenes and transitions](guides/scenes-and-transitions.md).

## Data and developer scenes

- **Reveal a bar, line, or pie chart.** See [Charts and data](guides/charts-and-data.md).
- **Show typed, highlighted code.** Use `Code` and `CodeReveal`; see [Code and terminal videos](guides/code-and-terminal-videos.md).
- **Animate a code diff.** See [Code and terminal videos](guides/code-and-terminal-videos.md).
- **Render a Mermaid diagram or a web page.** See [Diagrams and web views](guides/diagrams-and-webviews.md).

## Audio and captions

- **Add a music bed or a sound effect.** Use `Audio`; see [Audio and captions](guides/audio-and-captions.md).
- **React to the beat.** Use beat detection; see [Audio and captions](guides/audio-and-captions.md).
- **Burn in subtitles from an SRT or VTT file.** Use `Captions`; see [Audio and captions](guides/audio-and-captions.md).

## Look and feel

- **Brand a video from one palette.** Use `FluvieTheme`; see [Theming](advanced/theming.md).
- **Add grain, particles, or a shader.** See [Shaders and effects](advanced/shaders-and-effects.md).
- **Reuse one design across data rows.** Use a template; see [Templates](advanced/templates.md).

## Export

- **Render to MP4, GIF, an image sequence, or transparent WebM.** See [Exporting your video](guides/exporting-your-video.md).
- **Export the same video as reels, square, and landscape.** Use `Adaptive`; see [Multi-aspect](advanced/multi-aspect.md).
- **Write a poster frame.** Pass `--poster`; see [Exporting your video](guides/exporting-your-video.md).
- **Render in CI or on a server.** See [Rendering on a server](guides/rendering-on-a-server.md).

## Let AI do it

- **Author a whole video from a prompt.** See [AI and MCP](guides/ai-and-mcp.md).
- **Refine a video by describing the change.** See [AI and MCP](guides/ai-and-mcp.md).
